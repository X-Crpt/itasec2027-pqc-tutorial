About the tutorial

The standard is set. Implementing it well is the open problem.

Standardized post-quantum cryptography is moving toward deployment, but running an algorithm on a real device involves decisions the standard does not settle. Embedded platforms have to handle demanding kernels and memory requirements while keeping secret data safe from implementation attacks.

This tutorial connects both sides: making PQC practical through hardware/software design, and evaluating whether the resulting implementation is secure. Short case studies and demonstrations link each design decision to a measurable outcome.

Part 1 · Design

Hardware/software design for PQC

  • Implementation characteristics of representative PQC schemes
  • Finding bottlenecks in polynomial arithmetic and hash-based operations
  • Choosing between software, an instruction extension or a dedicated accelerator
  • Accelerator interfaces, data movement and memory footprint on RISC-V
  • Performance and energy of complete PQC operations
Part 2 · Security

Secure implementation of PQC

  • Side-channel and fault-injection threats relevant to PQC
  • Constant-time execution, masking and fault detection
  • Protecting keys and intermediate state
  • The processor–accelerator boundary: data transfers, shared resources and control signals

No prior experience with accelerator design is required.
